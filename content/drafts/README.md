# 미발행 원고

이 디렉터리는 `lib/posts.ts`에 등록하지 않는다. 공개 페이지나 사이트맵을 생성하지 않는다.

RAG 글의 2026-10-11 개편에서 상세 내용을 아래 편집 재료로 분리했다.

- `rag-construction.md`: 관계 추출, 별칭 통합, Local/Global 개념. 다음 편 후보.
- `rag-operations.md`: 규모, 갱신·삭제, 비용, 실험 설계. 운영 편 후보.
- `rag-alternatives.md`: LightRAG, HippoRAG 2. 별도 비교 편 후보.

첫 글은 기존 URL에서 검색 실패의 세 유형에 집중한다. 후속 글은 각각 질문 하나를 정해 퇴고하고 출처를 확인한 후 등록한다.

`jev-research-notes.md`는 Jev 글 개편 전 원고를 보존한 조사 기록이다.
가격·벤치마크·RAG 적용의 후속 글 재료이며 최신 사실로 인용하기 전에 재확인이 필요하다.

`aws-operations-notes.md`는 AWS 글의 2026-10-17 개편 전 원고다.
현재 공개 글은 롤링 배포의 요청 흐름에 집중하며, 원고의 넓은 운영 주제는 후속 편집 재료로 보존한다.

`git-collaboration-notes.md`는 Git 글 개편 전 원고다. 협업·병합·복구·릴리스는 후속 글 재료로 남겼다.
`astra-research-notes.md`는 Astra 글 개편 전 원고다. 이전 사양·가격·기능 비교를 최신 사실로 재사용하지 않는다.
